# EasyCast 电脑端

一个 Go 写的单文件 Windows 程序，把电脑上的内容推到电视上的「简易投屏」：

- **本地视频**：起 HTTP 文件服务（支持 Range，可拖动进度、暂停），电视直接拉原文件，不转码。
- **OBS 直播**：内置 RTMP 服务器接收 OBS 推流，再以 HTTP-FLV 提供给电视（例如把腾讯视频客户端的画面采集后推过去）。
- **控制页**：本机浏览器里的网页，填一次电视地址和口令，然后点按钮推送、暂停、继续、停止。

不依赖 Python、MediaMTX、ffmpeg。

## 编译

需要 Go 1.24 或更新（开发用的是 1.27）。

```powershell
cd pc
go build -ldflags "-s -w" -o easycast-pc.exe .
```

测试：

```powershell
go test ./... -count=1
```

## 使用

1. 双击 `easycast-pc.exe`（会打开控制页 `http://127.0.0.1:9000`），或者把视频文件拖到 exe 上直接推送。
2. 控制页里填**电视地址**和**口令**，两者都在电视主界面「电脑浏览器推送」那一行：
   - 电脑和电视在同一网段：填 `电视IP:8200`。
   - 不在同一网段（例如电视在华硕后面）：填路由器上做了 8200 端口转发的地址，如 `192.168.1.3:8200`。
   点「保存并连接」后，卡片上会明确写出**已连接 · 设备名 · 播放状态**（「空闲」只表示电视当前没在播放，和连不连上无关）；连不上时写**未连接 · 原因**。连上以后这个按钮变成**「断开连接」**，点它就不再访问电视（地址和口令仍保留在 pc.json 里），下次点「保存并连接」即可恢复，无需重填。断开期间推送会提示"还没有连接电视"。
   连上后还会出现**改名**一栏：输入新名字点「改名」（或回车），电视上的设备名立刻改掉，手机投屏列表里也会显示新名字（没变就退出投屏搜索再进一次）。名字存在电视上，电脑和电视重启都不会丢，电视主界面的「修改设备名称」改的是同一个名字。
   电视口令**不会每天自动更换**，长期不变，所以这里填一次就会被记住（存于本机 EasyCast/pc.json，重启后仍保留）；之后每天直接点「推送到电视」即可，无需重新填写。想换口令时去电视主界面点「更换口令」，再到本页重填一次并保存。
3. 放行 Windows 防火墙的 TCP `8000`（电视要从电脑上拉内容）：控制页里点「放行防火墙」（需要管理员身份运行），或手动添加入站规则。
4. 推本地视频：选文件，点「推送到电视」。
5. 推 OBS 画面：
   - OBS → 设置 → 推流：服务选「自定义」，服务器 `rtmp://127.0.0.1:1935/live`，推流密钥 `tv`。
   - 输出用 **H.264 + AAC**，关键帧间隔 1～2 秒，码率 3000～6000 Kbps，开始推流。
   - 控制页点「把 OBS 画面推到电视」。OBS 还没推流时，电视会等最多 20 秒。

## 端口

| 端口 | 绑定 | 用途 |
| --- | --- | --- |
| 9000 | 仅本机 | 控制页和接口 |
| 1935 | 仅本机 | OBS 推流（RTMP） |
| 8000 | 所有网卡 | 电视拉取本地文件、OBS 直播流 |

配置文件在 `%APPDATA%\EasyCast\pc.json`（含电视口令，仅当前用户可读），可改端口和 RTMP 监听地址。

## 安全

- 只有登记过的文件才会被提供，地址里带随机 id，电脑上其它文件不会被访问。
- 控制页只监听本机，并校验 `Host` 和 `X-EasyCast` 头，防止浏览器里的其它网页借它操作电视。
- RTMP 默认只监听本机，局域网里别人推不进来。要让别的电脑上的 OBS 推流，把配置里的 `rtmp_listen` 改成 `0.0.0.0:1935`。
- 电脑设置了系统代理（`HTTP_PROXY`）时，访问电视仍然走直连，不受代理影响。

## 限制

- 只支持 H.264 + AAC 的 OBS 推流，不支持纯音频流。
- OBS 抓腾讯视频等带版权保护的画面可能是黑屏，这是内容保护生效，不是本程序的问题。
- 只测过 Windows；文件选择框、防火墙放行、打开浏览器这三项只在 Windows 上有效。
